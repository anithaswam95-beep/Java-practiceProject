# Java Practice Project

This repository is a Java practice project focused on learning automation concepts using Java and Selenium.

It acts as a small portfolio project showing hands-on Java learning, project setup, and early test automation work.

## Tech Stack

- Java
- Eclipse project setup
- Selenium automation concepts
- Test automation basics

## Project Structure

```text
Java-practiceProject/

├── bin/
├── .classpath

├── Java practiceProject.iml
├── .idea/
├── .settings/
└── README.md
```

## What this project includes

- Java source code practice
- Learning project organization
- Selenium and automation exploration
- A foundation for more advanced testing work

## Prerequisites

- Java JDK
- IDE such as Eclipse or IntelliJ
- Browser installed for Selenium testing

## How to run

Open the project in an IDE and run the Java classes under the `src` folder.
